## 我在做什么

从界面、API 到部署，我关注实用工具和可复用的组件。目前的项目围绕浏览器工具、个人桌面体验，以及 Cloudflare 应用展开。

## 常用技术

- **界面：** TypeScript、React、Next.js、TanStack、Vue、Tailwind CSS。
- **服务：** Go、Node.js、Bun、PostgreSQL、Redis。
- **部署：** Cloudflare Workers、Docker、GitHub Actions。
- **也在探索：** Rust 和区块链集成。
